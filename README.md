# Data Compression

This repository contains two college projects for the subject **Data Compression and Protection**.

## Projects

- [Project 1](project1/README.md) implements byte entropy, Shannon-Fano, Huffman, LZ77, and LZW compression algorithms.
- [Project 2](project2/README.md) implements LDPC codes, syndrome decoding, and Gallager B decoding.

Both projects use Java 21 and Maven.

## How to run

Open the project directory, compile it, and follow its README:

See [Project 1 instructions](project1/README.md).

See [Project 2 instructions](project2/README.md).
